# Adventure Trip MG — prototype Android

Cette version contient un écran d’accueil, une recherche, des filtres, des fiches d’expériences et un formulaire de projet sur mesure.

## Limites
C’est un prototype de démonstration. Les tarifs sont indicatifs. Le formulaire ne transmet aucune donnée. Les comptes, réservations réelles, paiement Mobile Money, notifications, cartes hors ligne et interface d’administration connectée ne sont pas encore opérationnels.

## Générer l’APK avec GitHub
1. Importer le contenu de ce ZIP dans le dépôt `laurencioandria1-eng/Adventure-trip-mg` en gardant les dossiers `lib/` et `.github/`.
2. Ouvrir l’onglet Actions du dépôt.
3. Choisir **Build Android APK**, puis **Run workflow** sur `main`.
4. Si l’exécution termine en vert, ouvrir son détail et télécharger l’artefact **Adventure-Trip-MG-APK**.
5. Extraire le fichier `app-release.apk`, puis l’ouvrir sur Android pour l’installer.

Si le workflow échoue, l’APK n’a pas été produit : consulter la première étape rouge dans Actions.
